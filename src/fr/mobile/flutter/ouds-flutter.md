## OUDS-Flutter
OUDS-Flutter est le framework de développement mobile multi-plateforme qui implémente Orange Unified Design System.

### Présentation
OUDS-Flutter est une librairie de code développée en Flutter / Dart. Elle permet la mise en place rapide d'une application mobile, iOS et Android, accessible aux couleurs de la charte Orange. Avec l'utilisation des Design Tokens, Orange Unified Design System est capable de gérer les thèmes des différentes marques du groupe et les modes sombre et clair.

### Pourquoi l'utiliser ?
- Un style graphique commun à tous les services
- Une mise à disposition de composants pour les designers
- Une mise à disposition de composants pour les développeurs mobile
- Une accessibilité optimisée depuis le design jusqu'au code
- Une gestion native du multi-mode (mode clair, mode sombre)
- Une gestion native du multi-marque
- Une fluidité de production entre les designers et les développeurs grâce aux Design Tokens
- Un accès au code simplifié avec un code open source sous Licence MIT
