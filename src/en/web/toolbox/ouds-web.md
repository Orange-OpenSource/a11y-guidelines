# OUDS (Orange Unified Design System)

**OUDS-Web** is a development framework that integrates Orange Unified Design System. This framework is an evolution of Orange Boosted that takes into account the new Design System of Orange: Orange Unified Design System.

## Presentation

OUDS-Web is an HTML, CSS and JavaScript framework based on Bootstrap. It allows to quickly build responsive and accessible websites applying the Orange brand. With the use of Design Tokens, Orange Unified Design System is able to apply themes of different brands of the group and manage light and dark modes.

## Why use it?

- A common graphic style for all our services
- Ready-to-use components for designers
- Ready-to-use components for web developers
- Optimized accessibility from design to code
- Multi-mode support by design (dark mode, light mode)
- Multi-brand support by design
- Production workflow optimization between designers and developers, supported by a single vocabulary using Design Tokens
- Simple access to the Open Source code under MIT License
