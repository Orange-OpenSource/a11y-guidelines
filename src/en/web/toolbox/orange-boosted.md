# Orange Boosted

**Orange Boosted** is the web development framework that supports the Orange Design System. It is intended to be replaced by the Orange Unified Design System and its development framework [OUDS-Web](https://web.unified-design-system.orange.com/orange/).

## Presentation

Orange Boosted is an HTML, CSS, and JavaScript framework based on the very popular [Bootstrap](https://getbootstrap.com/).
It enables the rapid creation of a responsive and accessible website, adhering to Orange's brand guidelines.

## Why use it?

- Based on [Bootstrap](https://getbootstrap.com/)
- Enhanced with more accessible components
- Enriched with Orange-specific components
- Illustrated with example pages
- Open source under MIT license
