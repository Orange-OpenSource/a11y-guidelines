## OUDS-iOS
OUDS-iOS is the iOS development framework that implements Orange Unified Design System.

### Presentation
OUDS-iOS is a code library developed in Swift UI. It enables the rapid development of an accessible mobile application, adhering to Orange's brand guidelines. With the use of Design Tokens, Orange Unified Design System is able to manage the themes of the group's different brands, as well as dark and light modes.

### Why use it?
- A common graphic style for all services
- Provision of components for designers
- Provision of components for mobile developers
- Optimized accessibility from design to code
- Native multi-mode management (light mode, dark mode)
- Native multi-brand management
- Streamlined production workflow between designers and developers thanks to Design Tokens
- Simplified code access with open source code under MIT License
